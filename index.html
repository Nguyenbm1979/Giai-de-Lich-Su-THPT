    2 Giải bằng Gemini Pro gói Pro của bạn • không cần API key

    🚀 Tự động gửi sang Gemini Pro đang tìm tiện ích Chrome…

    Trang sẽ gửi ảnh/PDF/Word đề ở mục 1 và prompt, chờ Gemini trả lời rồi tự điền kết quả. Giữ Chrome mở và đừng đóng tab Gemini.

    Chưa thấy tiện ích. Cài theo hướng dẫn trong thư mục TienIch-Chrome-GiaiDeSu của repo (Chrome → chrome://extensions → Chế độ nhà phát triển → Tải tiện ích đã giải nén), rồi tải lại trang. Hoặc dùng cách thủ công bên dưới.

    📋 Không có tiện ích? Làm thủ công: sao chép prompt rồi dán kết quả
    1. Bấm 📋 Sao chép prompt, mở gemini.google.com, chọn bản Pro/Thinking, dán prompt.
    2. Đính kèm ảnh/PDF đề (và SGK nếu muốn) rồi gửi.
    3. Sao chép toàn bộ câu trả lời, dán vào ô dưới và bấm Dùng kết quả này — trang sẽ hiển thị, đối chiếu đáp án và xuất Word như bình thường.

    Lưu ý: cách này không có tọa độ để tự cắt hình minh họa. Nếu Gemini trả lời làm nhiều đợt, tích “Nối thêm” bên dưới khi dán đợt sau.

    4 Lịch sử các lần giải

    Lưu tự động trong trình duyệt này (tối đa 20 lần gần nhất, kèm cả ảnh/PDF đề để cắt hình lại). Xóa dữ liệu trình duyệt sẽ mất lịch sử.

      ⚙️ Giải bằng API key Gemini ít dùng hơn — bấm để mở

      Dùng khi bạn muốn trang tự gọi Gemini bằng API key (không qua tab Gemini). Kết quả hiện ở mục 3 phía trên.

      ① Cài đặt API key & mô hình

      Lấy key miễn phí tại aistudio.google.com/apikey. Key chỉ lưu trong trình duyệt máy này (localStorage), không gửi đi đâu khác ngoài Google.

      Nên chọn bản Pro (suy luận mạnh, đọc ảnh/PDF tốt). Bấm Tải danh sách để chọn mô hình mà key của bạn hỗ trợ. Nếu chưa tải, mặc định dùng gemini-3.1-pro-preview.

      ⚙️ Prompt hệ thống (đã điền sẵn — chỉ sửa nếu cần)

      ② Nạp SGK lên AI — chỉ cần khi dùng API key (dùng Kỹ năng/Gem của Gemini thì sách đã có sẵn trong đó)

      Tải PDF SGK Lịch sử 10, 11, 12 (Kết nối tri thức) và Chương trình GDPT 2018 để AI bám sát sách, không lấy nguồn ngoài. Tải 1 lần, dùng lại trong 48 giờ.

      📚 Bấm hoặc kéo–thả file PDF sách giáo khoa vào đây
      ⚙️ Thiết lập Google Drive (làm 1 lần)

      Cần 2 thông tin từ Google Cloud Console (miễn phí):
      1) Tạo project → APIs & Services → Library → bật Google Drive API và Google Picker API.
      2) Credentials → Create credentials → API key → dán vào ô “API key (Picker)”.
      3) Create credentials → OAuth client ID (loại Web application), mục Authorized JavaScript origins thêm https://nguyenbm1979.github.io → dán Client ID vào ô dưới.
      4) OAuth consent screen: chọn External, thêm email của bạn vào Test users. Chỉ xin quyền drive.file (chỉ đọc những file bạn chọn), không cần xét duyệt.

        💡 Sách được ghi nhớ ngay trong trình duyệt máy này: chọn 1 lần, các lần sau tự nạp lại — không cần chọn lại 9 file. Mẹo: chỉ nạp sách lớp liên quan đề để chạy nhanh hơn.
